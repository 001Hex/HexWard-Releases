Privacy Policy

Last updated 27 November 2026 · Hex Modifications

HexWard is an app for Windows and Mac that watches which programs are set up to start automatically. It is designed to need as little from you as possible.

What HexWard collects

Nothing. HexWard has no accounts, no analytics, no crash reporting and no telemetry. Hex Modifications does not receive any information about you or your computer.

Network use

HexWard makes no network connections and contains no networking features such as an updater or analytics. Code signatures are checked offline, with online revocation checks switched off. You can confirm this yourself with a firewall such as GlassWire (Windows) or LuLu (Mac).

What it reads and stores

To do its job, HexWard reads the places programs use to start automatically: on Windows, registry Run keys, Startup folders, scheduled tasks, services, drivers, sign-in hooks and WMI subscriptions; on Mac, launch agents and daemons, app helpers, cron jobs and shell startup files. It reads them; it never changes them.

It saves one thing: a list of the startup items it has seen (their names, locations, commands and a fingerprint of each) plus your "mark OK" decisions and a short activity log, so it can tell you when something is new or has changed. This is stored only on your computer, in %LOCALAPPDATA%\HexWard on Windows and ~/Library/Application Support/HexWard on Mac, along with your settings. Delete that folder to remove it. Reports are only created if you choose "Export report", and are saved where you choose.

Permissions

HexWard runs as a normal user. It does not ask for administrator rights, Full Disk Access, or access to your camera, microphone, location, contacts or notifications. If you turn on "Start HexWard when I sign in", it adds one entry for itself, which you can turn off at any time.

Downloads

The app is distributed through GitHub Releases. GitHub has its own privacy policy and may log download requests.
