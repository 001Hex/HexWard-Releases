Where malware hides, watched.

Malware, crypto miners and pushy apps all want to start themselves automatically, because that's how they survive a restart. HexWard keeps an eye on every one of those places and only speaks up when something changes.

Alerts the moment it appears

A new startup item shows up within seconds as a small card with a plain-English verdict. Mark it OK once and it stays quiet until it changes.

All in one panel

Everything that can run without asking, sorted by risk: what it runs, who signed it and where it lives.

Risk, in plain English

Five levels from Clear to Critical. Every flag is one fact you can check, not a mystery score.

Private by design

It never edits, disables or deletes anything. No network, no telemetry, no accounts, no admin password.

Native on Mac and Windows

It sits in the Windows system tray and the Mac menu bar, with the same look and the same rules on both.

Install in a minute

  1. Download HexWard-x.y.z-win-x64.zip (or win-arm64 for ARM PCs) and unzip it.
  2. Run HexWard.exe. Nothing to install: a shield appears next to the clock and tells you how many startup items it's watching.
  3. First launch: the preview isn't code-signed yet, so SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.
  4. Optional: in Settings, turn on Start HexWard when I sign in to Windows.

Check your download against the SHA-256 on the release page: Get-FileHash .\HexWard-*.zip -Algorithm SHA256

Questions

Is HexWard an antivirus?

No. It doesn't scan files or block anything, and it's not a replacement for Microsoft Defender or other security software. It answers one question very well: what is set up to start automatically, and did anything new just appear?

Does it change or delete anything?

No. HexWard is read-only. It lists and explains startup items and never edits, disables or deletes them. You decide what to do; "Show in Explorer" just opens the folder.

Why does it flag something I installed myself?

Plenty of legitimate software is unsigned or runs from your AppData or Downloads folder. HexWard tells you exactly why it flagged an item. If you recognise it, click It's mine, mark OK and it stays quiet until that item changes.

Does it collect any data?

No. HexWard makes no network connections and has no telemetry, updater or account. Code signatures are checked offline. Its list of what it has seen and your decisions are stored only in %LOCALAPPDATA%\HexWard.

Does it need administrator rights?

No. It runs as you. A few areas, such as WMI subscriptions, can only be read as an administrator; the panel tells you what it couldn't see.

Why does Windows say "Windows protected your PC"?

The preview isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway, and check your download against the SHA-256 on the release page.

Is it open source?

No. HexWard is free, closed-source software by Hex Modifications. See the EULA.
